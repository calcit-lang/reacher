# Upgrade Reacher to Calcit 0.13.77 / 将 Reacher 升级到 Calcit 0.13.77

- Time / 时间: `2026-09-04T19:15:19Z`
- Agent: `codex-01a06d2a`
- Coordination issue / 协调 issue: [calcit-lang/calcit#745](https://github.com/calcit-lang/calcit/issues/745)

## English

Migrated the legacy 0.6.1 snapshot to the canonical 0.13.77 format and replaced the manually cloned dependency setup with `deps.cirru` and Caps. The JavaScript toolchain now pins `@calcit/procs` 0.13.77, Yarn 4.12.0, Node.js 24 in CI, and Vite 8.2.2. The obsolete tracked `compact.cirru` snapshot was removed.

The source migration updates tags, `Option` handling, map access, React state representation, and browser/React interop. JavaScript boundary reads are isolated in typed adapters backed by `js-ffi` contracts. Positive and negative Node smoke tests cover input, store, and task property contracts. Browser testing exposed a stale Calcit-style `.includes` call in the React memo comparator; it was changed to the explicit JavaScript method `.!includes` and the failing interaction was retested successfully.

CI now resolves locked modules, verifies the Calcit/procs toolchain, checks canonical formatting, runs check-only compilation, rejects dynamic method dispatch, enforces the reviewed native quality baseline, validates README snippets, runs JavaScript FFI contract tests, and builds the production site. Deployment remains push-only and no longer runs on pull requests.

Validation:

- `caps --ci` and `caps verify --toolchain`: 4 locked modules resolved; Calcit and `@calcit/procs` both 0.13.77.
- `yarn install --immutable`: passed with Yarn 4.12.0 on Node.js 24.4.1.
- `calcit calcit.cirru --check-only`: passed with Calcit 0.13.77.
- `calcit calcit.cirru analyze dynamic-methods --max 0`: passed with 0 findings.
- `calcit calcit.cirru analyze weak-types --only code-nil --summary-only`: no code-nil usage.
- `calcit calcit.cirru analyze deprecated`: no deprecated API usage.
- `calcit calcit.cirru analyze quality --baseline config/calcit-quality.cirru`: passed; no dynamic-call, nil, or deprecated-call debt. The reviewed legacy baseline retains 42 unresolved schema-dynamic slots and 4 minimal unsafe assertions at JS/React boundaries.
- `calcit calcit.cirru docs check-md README.md`: 7/7 blocks passed.
- `yarn test:ffi`: positive and negative boundary cases passed.
- `yarn vite build --base=./`: 93 modules built successfully with Vite 8.2.2.
- Browser smoke test: initial render, text input, Run action, and rendered task update passed without new console errors after the comparator fix.
